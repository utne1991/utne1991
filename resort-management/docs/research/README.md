# Thư viện nghiên cứu BeeSmart

## Nguồn thị trường dùng khi lập kế hoạch

1. [Tóm tắt căn cứ làm việc](MARKET-RESEARCH-WORKING-SUMMARY.md): định vị v1, scope pilot và quan hệ với thiết kế PMS đầy đủ.
2. [Báo cáo đầy đủ dễ đọc](MARKET-RESEARCH-2026-10-26.md).
3. [Bản nguyên văn](MARKET-RESEARCH-2026-10-26.raw.txt): giữ đúng bytes upload và hash.
4. [Tình trạng nguồn, giá và giả thuyết](MARKET-RESEARCH-SOURCE-REGISTER.md): báo cáo hiện thiếu URL trích dẫn, chưa có phỏng vấn/WTP/pilot.
5. [Manifest tệp nguồn](MARKET-RESEARCH-MANIFEST.json): ngày tiếp nhận, số byte, SHA-256 và phạm vi kiểm tra.

Người dùng đã yêu cầu dựa vào nghiên cứu để làm việc. Nó là nguồn tham chiếu chính cho discovery/backlog, chưa phải phê duyệt giá, API entitlement, provider hoặc baseline code.

## Nguồn kỹ thuật

[Đối chiếu ba PMS mã nguồn mở](PMS-BENCHMARK.md): snapshot và source/license đã đọc có chọn lọc. Không dùng benchmark kỹ thuật thay thế bằng chứng nhu cầu thị trường hoặc kết quả triển khai thực.
